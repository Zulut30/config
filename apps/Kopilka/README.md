# Копилка

Нативное приложение macOS 14+ для быстрых заметок, ссылок и находок. SwiftUI + AppKit, SQLite из системы. Без сторонних зависимостей, сервера и аккаунта.

## Запуск

```sh
./script/build_and_run.sh
./script/check.sh
```

Сценарий собирает `dist/Kopilka.app`, подписывает для локального запуска и устанавливает в `/Users/zulut/Applications/Kopilka.app`. Нужны Command Line Tools; полный Xcode не нужен. В Codex доступна кнопка Run.

## Сочетания

- `Control + Shift + N`: сохранить выделение, сохранив фокус исходного приложения.
- `Control + Shift + Option + N`: открыть выделение в маленьком окне с комментарием.
- `Control + Shift + I`: открыть библиотеку.
- `Command + Shift + V`: сохранить буфер, когда активно окно Копилки.
- Меню в строке меню: сохранить буфер, новая заметка, настройки.
- Службы macOS: «Сохранить в Копилку» в приложениях, поддерживающих передачу выделенного текста.

В настройках Копилки откройте «Универсальный доступ» и включите приложение. Глобальный хоткей регистрируется отдельно; разрешение требуется для копирования выделения. Если macOS спрашивает о доступе к буферу, разрешите его для захвата текста. После изменения разрешений вернитесь в Копилку. Автозапуск включается пользователем в настройках приложения.

## Что сохраняется

Исходный текст, ссылки из текста и доступного RTF/HTML, название приложения-источника, дата, теги, личный комментарий. Для GitHub формируется локальная карточка `owner/repo`; информация из интернета автоматически не загружается. Саму ссылку на сообщение Telegram приложение не выдумывает: она сохранится, если была скопирована вместе с текстом.

Некоторые приложения не предоставляют выделенный текст или скрытый адрес ссылки. В таком случае скопируйте сообщение/ссылку вручную и выберите «Сохранить из буфера». Снимки экрана и OCR в первую версию не входят.

## Хранение

`~/Library/Application Support/Kopilka/notes.sqlite` и служебные файлы SQLite WAL. Удаление отправляет заметку в локальную корзину с возможностью восстановления. Настройки позволяют экспортировать заметки в один Markdown-файл, пригодный для Bear и Obsidian. Экспорт содержит текст, ссылки, источник, даты и теги.

Буфер читается только по команде пользователя. Перед Cmd+C сохраняются его типы и данные; восстановление проверяет `changeCount`, чтобы не перезаписать последующее копирование. Нет фонового опроса, локальных моделей или сетевых запросов. Короткие ожидания используются только во время захвата и для скрытия уведомления.

## Проверки

Проверки `./script/check.sh` работают с Command Line Tools, без XCTest и полного Xcode. Они покрывают SQLite после повторного открытия, восстановление заметки из корзины, Unicode, распознавание GitHub и ссылок, RTF-ссылки, сохранение типов буфера и защиту от перезаписи нового копирования. Проверка межприложенческого захвата требует разрешения macOS и проводится в запущенном приложении.

Использованные системные API: [NSPasteboard](https://developer.apple.com/documentation/appkit/nspasteboard), [SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice).
